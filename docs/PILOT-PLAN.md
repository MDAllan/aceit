# Two-week pilot plan

**Goal:** show, with one real class, that students use ACEIT, that it helps them, and that instructors find the dashboard useful.

## Before day 1 (30 minutes)

- Create the school and the class (see `docs/SCHOOL-SETUP.md`, step 4). Connect the instructor.
- Agree the exam or quiz date and enter it, so students see a countdown.
- Tell the instructor what students will see and what the instructor can see (`docs/SECURITY.md`, sections 2 and 3). Share the privacy page link.
- Decide, with the school, whether the pilot needs a privacy impact assessment.

## Week 1

- Day 1: the instructor shows the join code in class (2 minutes). Ask students to join and answer one quiz.
- Day 3: the instructor opens the class page: who joined, who has not opened it, hardest questions so far. Tell the class which topics to revise.
- Day 5: ask for a rating and a comment (Profile > Send feedback).

## Week 2

- The instructor uses the hardest-questions list to choose what to review in class.
- Before the test, remind students that cards due for review are waiting.

## What we measure

| Measure | Where it comes from |
|---|---|
| Joined: students who joined / students in the class | Class page |
| Activated: students who finished at least one topic within 24 hours | Class page (progress above 0) |
| Weekly active students | Class page: active this week |
| Quiz accuracy, first attempts compared with later attempts | Class insights, CSV |
| Hardest questions | Class insights |
| Satisfaction | Student feedback ratings and comments; ask the instructor for 5 minutes at the end |

## Finish

- Produce a one-page summary (the numbers above, three quotes, what the instructor would change).
- If the class took a test, compare it with the previous term's result for the same test only if the instructor offers that data; do not ask for individual grades.
- Agree: continue, extend to more classes, or stop. If stopping, delete the class and its students on request.
